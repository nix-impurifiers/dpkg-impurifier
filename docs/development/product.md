# Product

A dpkg impurifier turns a Nix application into native net/offline `.deb` artifacts
and declarative host integration. Native install intent produces one shared,
GC-rooted application profile. The Nix runtime provider is consumer-configurable.

See the [README](../../README.md) for the supported API and operational contract,
and [design](../design.md) for the package-manager boundaries and deferred
installer, hardware and backend work. Published under `nix-impurifiers`.
